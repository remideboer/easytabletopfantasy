Classless (Optional Variant)

On this page

Classless is an optional variant of You-Meet-In-A-Tavern (YMIAT) that removes the class chassis. Instead of picking a class and unlocking its features by level, you spend XP to train individual abilities from a shared pool, at your own pace. Everything else about YMIAT — the three abilities, Wounds and Defense, Lineage, Heritage, Background, Talents, and Magic — works exactly as described elsewhere in the rules unless this page says otherwise.

Use this page instead of Classes

Classless replaces Classes as the character chassis. Everywhere else in the rules that says "your class determines…", read it as "your trained abilities determine…" for a Classless character. This is a Game Master option — agree on it with your table before character creation.

What Changes

  • No classes. Skip the "Choose a Class" step entirely. There is no class list, no per-class proficiencies, and no fixed spellcasting ability tied to a class.
  • Max Wounds is flat. Every Classless character starts with the same base instead of a class start value; see Max Wounds below.
  • Abilities are trained, not granted. Features that would normally come from a class or level (Rage, Sneak Attack, Spellcasting, and so on) are instead learned individually by spending XP; see Trained Abilities.
  • Silver is the everyday coin. Gold is rare and mostly a store of value, not pocket change. Starting funds and equipment prices are in silver pieces (SP); see Currency.
  • Lineage, Heritage, and Background are unchanged — you still choose all three as normal.

Character Creation (Classless)

Follow the same overall flow as standard Character Creation, with the class step replaced:

  1. Character Concept — as usual.
  2. Determine Ability Scores (Fitness, Insight, Willpower) — as usual, using Point-Buy or Standard Array.
  3. Choose a Lineage — as usual.
  4. Choose a Heritage — as usual.
  5. Choose a Background for its skills, tool/language proficiencies, and talent choice. Ignore its listed starting money and equipment package — Classless characters buy their own gear (see Currency).
  6. Pick your starting trained ability — one ability from the curated Classless ability list, free of charge; see Trained Abilities.
  7. Spend your starting silver on equipment from the Gear tables.

Max Wounds

Classless characters calculate Max Wounds without a class start value:

Max Wounds (Classless) Max Wounds = 4 + Fitness modifier

There is no automatic per-level increase, since Classless characters don't gain class levels. Instead, Max Wounds only goes up when you train an ability that says so — for example the Combat Conditioning talent, or an equivalent entry from the curated ability list. Everything else about Wounds — how they're inflicted, how they're healed, hearts, weakening, and Death Saves — works exactly as described in Wounds and Scale and Combat.

Trained Abilities (XP Economy)

In standard YMIAT, class features unlock automatically as you level. In Classless, there is no level gate — instead, every ability (from any class, plus general Talents) is drawn from one shared pool, and you unlock it by spending accumulated XP on it directly. Think of it as paying for training time rather than for character sheet space.

As in the core rules (see Level Advancement), a newly trained ability doesn't come online mid-scene — it becomes usable after a long rest or a period of dedicated study or practice (Game Master's discretion), reflecting the time it takes to actually learn it.

Starting Ability

At creation, choose one ability free of charge from the curated Classless ability list.

Training Cost

Each further ability costs XP to train. The exact cost per ability is still being tuned alongside the curated list above — treat the table below as a starting default you can adjust for your table, not a final number.

TierSuggested XP CostExample
Minor50 XPA skill/tool proficiency, a small utility feature
Core150 XPRage, Sneak Attack, Bardic Inspiration, a single Spellcasting school
Major300 XPExtra Attack, Wild Shape, full multi-school Spellcasting

These costs are pitched against the same scale as normal leveling (100 XP per level, see Experience Points), so a Core ability costs roughly as much XP as reaching character level 2. Subclass-style abilities and repeatable Talents (like Ability Score Improvement) can be trained the same way, at Game Master discretion.

Currency: Silver Standard

Classless assumes a lower-magic, more historically grounded economy: silver is the coin ordinary people actually use, and gold is uncommon enough to be a notable find rather than pocket change.

  • Starting funds: every Classless character begins with 100 SP, regardless of Background.
  • Equipment prices: use the SP/CP prices already listed on the Gear page — for example, a shortsword costs 60 SP.
  • Gold pieces (GP) still exist as a rare, high-value coin (roughly 10 SP per GP) for treasure and big-ticket transactions, but new characters don't start with any.

Ignore Background gold amounts

Backgrounds still list legacy starting money in gold pieces (a holdover that hasn't been converted to the silver-standard economy). For Classless characters, ignore that figure entirely and use the flat 100 SP above instead.

Everything Else Stays the Same

Classless only touches the character chassis, ability training, and starting currency. Everything else in the core rules applies unchanged:

  • Core Rules — dice and tests, proficiency and advantage, skills, Resolve, rests.
  • Combat — attacks, Defense, Life/Death Saves.
  • Lineages, Heritages, and Backgrounds — chosen exactly as normal (aside from the equipment override above).
  • Talents — part of the same trained-ability pool as class features.
  • Magic — spells work the same once a character has trained the relevant Spellcasting ability.
