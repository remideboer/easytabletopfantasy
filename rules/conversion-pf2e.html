Converting from Pathfinder 2e to You-Meet-In-A-Tavern (YMIAT)

On this page

This guide explains how to convert characters, rules, and mechanics from Pathfinder Second Edition (PF2e, Player Core) to You-Meet-In-A-Tavern (YMIAT)'s standard, class-based system. It targets the same eight classes Player Core defines — Bard, Cleric, Druid, Fighter, Ranger, Rogue, Witch, Wizard — all of which already exist in Classes, so most of this guide is about translating PF2e's different core math onto that existing chassis, not building new classes from scratch.

Approximate by design

PF2e and YMIAT resolve the game very differently under the hood — four degrees of success vs. binary hit/miss, level-scaling proficiency vs. advantage, a flexible three-action turn vs. action/movement/reaction. This guide picks one reasonable, consistent mapping for each and applies it throughout, the same way the D&D 5e guide does. Treat individual feats and spells as needing a look, not a guarantee — see Open Questions for what's still GM judgment.

Converting Attribute Modifiers

PF2e (2023 remaster) records attribute modifiers directly — Strength, Dexterity, Constitution, Intelligence, Wisdom, Charisma — with no separate 3–18 score to derive them from. Composite the three YMIAT abilities straight from those modifiers, the same grouping as the 5e guide uses:

  • Fitness = (Strength + Dexterity + Constitution modifiers) ÷ 3, rounded down.
  • Insight = (Intelligence + Wisdom modifiers) ÷ 2, rounded down.
  • Willpower = (Wisdom + Charisma modifiers) ÷ 2, rounded down.

Example: Converting Attribute Modifiers

Given PF2e modifiers Strength +3, Dexterity +1, Constitution +2, Intelligence +0, Wisdom +1, Charisma −1:

  • Fitness = (3 + 1 + 2) / 3 = 2 (round down) → +2
  • Insight = (0 + 1) / 2 = 0.5 → 0
  • Willpower = (1 + (−1)) / 2 = 0 → 0

The YMIAT modifiers are: Fitness +2, Insight +0, Willpower +0.

Converting Levels

PF2e characters advance from level 1 to level 20 — the same range as D&D 5e — so the identical mapping applies: every two PF2e levels combine into one YMIAT level.

  • Levels 1–2 → YMIAT level 1
  • Levels 3–4 → YMIAT level 2
  • Levels 5–6 → YMIAT level 3
  • Levels 7–8 → YMIAT level 4
  • Levels 9–10 → YMIAT level 5
  • Levels 11–12 → YMIAT level 6
  • Levels 13–14 → YMIAT level 7
  • Levels 15–16 → YMIAT level 8
  • Levels 17–18 → YMIAT level 9
  • Levels 19–20 → YMIAT level 10

Converting Proficiency Ranks

PF2e's proficiency bonus is level + a rank bonus (Untrained +0, Trained +2, Expert +4, Master +6, Legendary +8), applied to nearly everything — AC, attack rolls, Perception, saving throws, skills, spell effectiveness. That linear, ever-growing bonus doesn't fit YMIAT, which uses advantage instead of stacking flat bonuses. Convert rank to stacked advantage instead, reusing the "double advantage" language already used for Spell School Expertise and the Classless Weapon Expertise ability:

PF2e RankYMIAT Equivalent
UntrainedNo advantage (flat d20)
TrainedAdvantage (roll 2d20, take highest)
ExpertDouble advantage (roll 3d20, take highest)
MasterTriple advantage (roll 4d20, take highest)
LegendaryQuadruple advantage (roll 5d20, take highest)

Apply this to whatever roll the PF2e rank was modifying: an Expert attack proficiency becomes double advantage on that attack roll; Master in a saving throw becomes triple advantage on that save; and so on. A character's rank in a given statistic rarely exceeds Expert before YMIAT level 5–6 (PF2e level 10–12) — don't front-load Master or Legendary onto a low-level conversion just because the PF2e source eventually gets there.

Converting Degrees of Success

PF2e resolves every d20 roll — attacks, saves, skill checks, spell effects — into one of four outcomes, and a great deal of PF2e content (spell descriptions, reactions, monster abilities) is written directly against those four outcomes. Rather than flattening that back to a binary hit/miss, layer PF2e's margin rule on top of YMIAT's own d20 rolls for any check made against PF2e-converted material:

Degree of Success result = d20 + modifiers
  • Critical success: result meets or beats the DC by 10 or more.
  • Success: result meets or beats the DC.
  • Failure: result is below the DC.
  • Critical failure: result is below the DC by 10 or more.

A natural 20 shifts the outcome one step better (success → critical success, failure → success); a natural 1 shifts it one step worse — exactly as in PF2e. On advantage rolls, apply this to the die you keep, after picking the higher (or lower, on disadvantage) result.

This only applies where the converted material actually specifies a critical effect. For anything that only ever had a hit/miss in the source, YMIAT's normal single-Wound-per-hit, two-on-a-crit combat math still applies unchanged.

Converting Max Wounds

PF2e Hit Points run much higher than D&D 5e's — a PF2e Fighter alone gains 10 + Constitution modifier every level, before ancestry HP or Toughness feats — but that's not something to reconvert from scratch. Since PF2e's eight classes already exist in YMIAT with their own Max Wounds bases already tuned for YMIAT's Wounds scale, just use the identically-named class's existing value unchanged:

Max Wounds Max Wounds = YMIAT class Max Wounds base + Fitness modifier + ( level − 1 )

See each class's entry on Classes for its base (for example, Fighter and Ranger start at 10 + Fitness modifier; Wizard and Witch at 8 + Fitness modifier — see the class page for exact current values). PF2e's higher HP total is already "priced in" to how tough that class is designed to feel; it doesn't need a separate divisor the way monster stat blocks do.

Converting Weapons and Damage

PF2e's base weapon damage dice are the same familiar d4–d12 range as D&D 5e (a longsword is 1d8 in both games), so the 5e dice-to-bonus table applies unchanged:

  • Unarmed: +0
  • d4: +1
  • d6: +2
  • d8: +3
  • d10: +4
  • d12: +5
  • 2d6: +6

PF2e adds extra damage dice from several places D&D 5e doesn't: striking runes (multiply the weapon's base dice), the deadly trait (extra die on a critical hit only), and precision-based class features. Convert each extra die the same way and add it to the weapon bonus; for a deadly or crit-only die, apply that extra bonus only when the attack roll is a critical hit (see Converting Degrees of Success).

The multiple attack penalty (PF2e: −5 on your second attack action in a turn, −10 on the third and beyond; agile weapons reduce this to −4/−8) maps directly onto YMIAT's existing Stacking Disadvantage and Agile Weapons rules for extra attacks in a turn — no separate penalty needed, the systems already match conceptually.

Converting Wounds (Spells and Effects)

Use the same conversion as the 5e guide: take the maximum total of the damage dice expression, divide by 6, and round to the nearest whole number. PF2e spell damage scales by adding dice as the spell is heightened to a higher rank — convert the dice at whatever rank is being cast, the same way you'd convert a 5e spell cast with a higher-level slot.

Converting Armor Class

PF2e's Armor Class = 10 + Dexterity modifier (capped by the armor) + proficiency bonus + armor's item bonus. Split this the same way as attack and save proficiency above:

  • Armor's item bonus → YMIAT Defense bonus, taken directly from the Armor table for the equivalent armor category, same as a 5e conversion.
  • AC proficiency rank (Trained/Expert/Master/Legendary in armor) → advantage on the Defense roll, using the same stacked-advantage table as Converting Proficiency Ranks above, instead of a flat number.

For an unarmored character, Defense = Fitness modifier, same as standard YMIAT.

Converting the Action Economy

PF2e turns are three flexible actions (Strike, Stride, Raise a Shield, cast a spell that costs 1–3 actions, and so on), which doesn't map cleanly onto YMIAT's default action + movement + reaction turn. Use YMIAT's optional 3 Moments System instead — it already splits a turn into three spendable units for movement, attacks, and spellcasting, the closest existing match:

  • A PF2e 1-action activity (Strike, Stride, Raise a Shield, Interact) costs 1 Moment.
  • A PF2e 2-action activity (most spells, Sudden Charge-style combos) costs 2 Moments.
  • A PF2e 3-action activity (a handful of powerful class feats and rituals) costs all 3 Moments for the turn.

PF2e's free actions and reactions convert directly to YMIAT's free actions and reaction, unchanged.

Open Questions

Still to work out

  • Dying, Wounded, and Doomed. PF2e tracks death with a numeric dying value instead of YMIAT's three-hearts/Death Save system. These don't map 1:1 yet — for now, treat reaching 0 Wounds as triggering a normal YMIAT Death Save, and ignore the PF2e dying/wounded/doomed values entirely.
  • Class-by-class feat conversion. This guide covers the shared math; each class's specific feats, class features, and spellcasting progression (Bard, Cleric, Druid, Fighter, Ranger, Rogue, Witch, Wizard) still need converting individually into that class's existing Class Abilities entry.
  • Ancestry feats and heritages. PF2e's ancestries (Dwarf, Elf, Gnome, Goblin, Halfling, Human, Leshy, Orc, plus Versatile Heritages) need mapping onto YMIAT's Lineages and Heritages — not yet started.
  • Spell list conversion. PF2e's spell rank (1st–10th) roughly lines up with YMIAT spell level, but PF2e's four spellcasting traditions (Arcane, Divine, Occult, Primal) and its Spell Points-free slot system still need a pass against YMIAT's Magic list and Spell Power economy.
