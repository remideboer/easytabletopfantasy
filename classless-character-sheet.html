Classless Character Sheet

A digital sheet for the Classless variant of You-Meet-In-A-Tavern (YMIAT). Stat boxes work like the standard Character Sheet; everything else is free-form text, since Classless abilities are trained individually rather than picked from a fixed class list. Saved in this browser (no account needed).

Select a character from the list, or create a new one to open the sheet.

Changes save automatically. Max Wounds, Spell Power, Defense, and Resolve are tracked by hand here since Classless abilities aren't fixed to a class — see the Max Wounds and Spell Power rules for the formulas to apply as you train. Click an Abilities slot to pick a trained ability from the list.
